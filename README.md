# Gale Protocol (opBNB & IDRX)

Smart contract protocol and decentralized settlement layer for **Gale (Sosmed Galley)** — A Real-World SocialFi & Hyper-Local Community Super-App built on the BNB Chain ecosystem.

---

## 🌟 Key Architecture

- **Attention Economy (AdFi)**: Automatically routes 20% of advertiser deposits to the platform treasury and locks 80% in the `AdRewardVault` contract for viewers.
- **EIP-712 Cryptographic Claims**: Users claim IDRX micro-rewards on-chain using signatures verified by the AI Proof-of-Human-Attention engine.
- **Gasless User Experience**: Sub-cent transaction fees on opBNB / BNB Chain are sponsored via Paymaster relayer architecture.
